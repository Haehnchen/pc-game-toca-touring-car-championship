# Graphics Setup

The canonical frontend builds this menu in `0046a11f` at `004b7a18`: up to five
normal icon rows; the first four adjust values directly (next-state fields all
point back to state 30, so Detail has no submenu).

| Original row | Configuration field | Behavior / source |
| --- | --- | --- |
| Low/Medium/High Resolution | root `+0x324` | `0046a2eb`; 320×240, 512×384, 640×480, skipping unsupported modes via `0046a030`/`0046a4b7` |
| Low/Medium/High/Very High Detail | root `+0x328` | Values 0–3; `0046a286` labels; `0046a393` cycles either direction |
| Display Device N | root `+0x648`; count `+0x644` | `0046a5a8`/`0046a679` cycle enumerated DirectDraw adapters; help shows the adapter name |
| Split: Vertical/Horizontal | root `+0xd8` | `0046a337`/`0046a438`; toggles two-player screen orientation |
| Back | — | Returns to Game Options, state 28 |

- Icons 59,53,60,6,16. Detail labels: localized tables `004b1390`, `004b13a8`,
  `004b13c0`, `004b13d8`; help `004b1468`. Hidden-row flags are distinct from
  availability: `0046a11f` hides Display Device with fewer than two adapters;
  `00468852` can hide Resolution and force Low on the primary adapter with
  restricted video memory. Backend selector: command-line argument 2
  (`00482d38`); `00482bab` classifies DirectDraw video memory; backend 1 forces
  one device.
- `0046a8bb` defaults split orientation to Horizontal; with an initialized
  display: Low Resolution/Medium Detail for backend 1 or memory class 2, else
  High Resolution/Very High Detail; it initializes CD music to 40%. Presets
  affect the detail-specific scenery member (`0044e7bb`), car model thresholds
  and track distances (`00452376`), additional geometry (`004392d0`/`00439500`).
- Split label: `0046a337`'s `%s: %s` format (`004ae8c8`) and localized
  Split/Horizontal tables `004b1408`/`004b1420`/`004b1438` (German
  `TEILUNG: HORIZONTAL`).

## Native menu

- Keeps the four-level Detail control and adds Mega; original localized whole
  labels (Very High Detail); Left/Right/Enter wrap as in the original.
  Rows: Resolution, Fullscreen, VSync, FPS Limit, Apply and Save, Detail, Split,
  Back; original left-aligned icon rows, 88×56 icons, 68-pixel row spacing,
  original font sizes. Eight entries form pages of five and three; Apply and
  Save ends page 1, Detail starts page 2; Up/Down switches groups and wraps.
- Resolution shows large pixel dimensions (no heading); aspect suffix in the
  same font/baseline; the two missing parentheses are enlarged from the help
  font into the menu atlas; long custom dimensions share one fitting pass. Each
  label shows the exact reduced aspect ratio (8:5 spelled 16:10).
- Icons 59/53/6/29/16 for resolution/detail/split/save/back. Fullscreen, VSync,
  FPS use native corner/arrow-loop/gauge symbols on the palette-colored metal
  badge (generated by palette-aware code), with selected variants. Controller
  Back uses its original icon row. Apply label: `APPLY / SAVE`,
  `APPLIQUER / SAUVER`, `ANWENDEN / SPEICHERN` (German 392 px in the 405 px text
  area, large font).
- Detail changes apply and save immediately as `graphics_detail=0..4`, including
  switching to/from Mega. Pending display/split edits remain staged until
  Apply and Save (`split_vertical=on|off`); Back/Escape discards those drafts
  while retaining the selected detail. Config/CLI: `graphics_detail` / `--graphics-detail`.
  Fresh settings: Mega, native 1280×720 (16:9) (other resolutions
  selectable), 100% effects/CD/master volume, game music and stereo on (the
  original 40% CD music default deliberately not followed). Saved values and CLI
  overrides take precedence. The original low-memory auto-downgrade is not
  needed.
- Native resolution choices (incl. widescreen) replace the three original
  modes. DirectDraw adapter selection is tied to the old backend; the SDL GPU
  service chooses its device, so no adapter row. Split toggles with the normal
  option cue and has the original Horizontal default; Local Single Race with
  Players:2 uses the saved orientation for cameras and HUDs
  ([split screen](split-screen.md)).

- All five profiles use the same `GROUND.C3D`; object collections have three
  source variants; Mega adds replacements for selected models/materials
  ([track upgrade audit](mega-track-materials-plan.md#track-models-per-detail-level-and-shared-upgrade)).
- The saved setting enters `SceneSelection.detail` on scene load (incl. race
  re-entry). Mega (detail 4) adds optional per-car GLB overrides, falling back
  to Very High car resources ([model generation and limits](cm3d.md#mega-glb-models)).
  Mega doubles the maximum view distance and the two short object-distance
  thresholds; vehicle HIGH/MEDIUM ranges 20/40 → 40/80 units and the original
  four-HIGH/five-MEDIUM budget is removed. View angle and original detail 0–3
  distances unchanged ([sector selection](scene-rendering.md#sector-selection)).
  Rebuilt cones/posts/signs on all ten tracks, HOR aircraft/helicopters/
  balloons/Audi airship with original-livery WebP redraws
  ([scene materials](scene-models.md#mega-track-props-and-scenery)); Mega HUD
  ([Mega HUD](session-hud.md#mega-artwork)); ten Mega loading screens with
  source-metric statistics font
  ([loading artwork](scene-lifecycle.md#mega-loading-bitmaps-and-original-statistics)).
  Original High/Very High keep canonical car models.
- Details 0–2 select original LOWPOINT barrier data; all ten tracks keep
  identical route records for qualifying, lap checkpoints and AI. Display/audio
  timing unchanged.
